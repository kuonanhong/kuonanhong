FOR VISITORS

觀眾實際感受是什麼？

影片開頭建議以「一整個展廳實景」開場，配合旁白，讓評審與觀眾在 10 秒內理解： 這不是 VR 頭盔，而是一個「站在現場就能看到的活的全像畫作」。

場景一：博物館入口的 Holo-Mona Lisa

鏡頭推進一幅懸浮於空中的〈蒙娜麗莎〉全像。三位觀眾（U1 學生、U2 家長、U3 外國遊客）站在不同位置， 畫面切成三分割：

  • U1 微笑 → 蒙娜麗莎嘴角上揚，眼神跟隨他移動。
  • U2 開口發問 → 畫作開口以自然語音回應，並搭配嘴型動畫。
  • U3 安靜觀察 → 保持經典中性神情，維持策展一貫性。

旁白一句話總結： 「同一幅作品，因為你的表情、你的問題、你的站位，而為你做出專屬回應。」

場景二：從觀眾視角切換到系統視角

影片中段建議加入一個「翻面」效果，將畫面翻到背後，看到：

  • CAM1 / CAM2 / CAM3 從不同角度拍攝 U1、U2、U3。
  • Edge Server / Cloud (NVIDIA Jetson / A100) 進行即時表情與語音分析。
  • Generative A.I. 產生「Response Commands」，為每位觀眾生成對應影像與語音。
  • LCoS / SLM / HOE / Photonic Crystal 模組將不同影像分別送往不同觀看角度。

旁白可以簡短補充： 「我們把原本屬於雲端的 AI 算力推到展場邊緣，讓互動延遲低於 35ms，頻寬需求比傳統雲端串流少 99.7%。」

SYSTEM WALKTHROUGH

對評審與技術觀眾的 5 步驟說明動畫

以下五個步驟可以直接對應到您手繪圖（LINE_NOTE_250926_1.jpg）中的編號 ①–⑤，並與論文中四層架構 （感知層、邊緣智能層、協作與渲染層、顯示與反饋層）同步介紹。

1

① Shared Mona Lisa Asset：多層全像內容

疊加多張數位資產：中性蒙娜麗莎、表情變化、嘴型動畫、體積影片 (Volumetric Videos)。 這些素材會在 Omniverse 或類似 3D 協作平台中作為「場景基底」。

2

② Edge Server / Cloud：聯邦學習 + 生成式 AI

在展場機房部署 NVIDIA Jetson / A100，執行表情辨識、語音理解與生成式 AI。多個展場可以透過 聯邦學習 (Federated Learning) 共享模型更新，而不交換原始人臉與語音資料。

3

③ Different Observers：姿態 / 心情 / 站位皆不同

CAM1、CAM2、CAM3 從不同角度拍攝觀眾，辨識其表情、注視方向與姿態。系統為每位觀眾產生 一個 Response Command，例如 (user:1, action:smile, intensity:0.8)。

4

④ LCoS / SLM / HOE 堆疊：角度多工

LCoS / 光子晶體 / 全像光學元件堆疊，將不同用戶的全像圖分離到不同角度，達到「一塊面板、 多個觀看區域、互不干擾」。這一段可搭配簡單 3D 線框動畫呈現光路。

5

⑤ Volume Videos & Spatial Audio：真正沉浸感

透過體積影片與波束成形揚聲器陣列，讓每位觀眾在各自的位置同時感受到 3D 動畫與個人化空間音訊， 但彼此之間互不干擾，保留公共空間的社交性。

FOR JUDGES & INVESTORS

2 分鐘內說清楚的價值主張

這一段建議在影片後半段或網頁導覽時，直接切換成「投資人視角」：市場痛點、解決方案、技術護城河與 財務潛力。數字可參考商業計畫書與論文中的模擬結果。

一、我們解決的痛點

  • 現有展場多為單向播片，缺乏人味與記憶點。
  • VR / AR 需要穿戴頭盔，破壞公共場域的社交感。
  • 雲端串流延遲與頻寬昂貴，不適合大量即時互動。

二、Holo-Artisan 的解法

  • 多用戶、無穿戴、即時個人化全像顯示。
  • 邊緣 AI + 聯邦學習：延遲 < 35ms、頻寬節省 > 99%。
  • 從硬體系統 → 內容平台 → SaaS / PaaS 生態系。

三、關鍵技術與財務指標（影片可用動畫呈現）

< 35 ms 端到端互動延遲（相比傳統雲端約 170 ms），符合沉浸式體驗需求。
99.7% ↓ 相較雲端串流，高達 99.7% 的頻寬節省，適合多展場大規模部署。
500k → 27 ms GPU 加速 CGH：50 萬個 3D 點在約 27 ms 內生成全像圖，支援 30 FPS 動態內容。

影片最後，可用一張簡單曲線圖呈現「三年內由 PoC → 標準產品 → 平台化」的收入成長路徑，對應種子輪 50 萬美元資金需求與未來 A 輪規劃。
